# /prompts

Los 7 prompts del SDLC (Componente 3). Cada uno pasa por la plataforma de
validación antes de usarse como plantilla de ejecución.

| Archivo | Fase |
|---|---|
| `requirements.md` | 1. Requerimientos |
| `analysis_specification.md` | 2. Análisis / Especificación |
| `architecture.md` | 3. Arquitectura / Diseño |
| `implementation.md` | 4. Implementación |
| `testing.md` | 5. Testing / QA |
| `deployment.md` | 6. Deployment |
| `maintenance.md` | 7. Mantenimiento |

`validation_metrics.csv` registra por prompt: versión inicial, métricas
iniciales, versión optimizada, métricas posteriores, delta, versión aprobada,
fecha, modelo y id del run en la plataforma.

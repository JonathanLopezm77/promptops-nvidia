# /benchmarks

Benchmark de modelos (Componente 4): 3 modelos × 3 fases (Requisitos,
Arquitectura/Diseño, Implementación) × 3 corridas = 27 ejecuciones auditables.

- `results.csv` — métricas agregadas por modelo y fase
- `execution_log.csv` — una fila por ejecución: fecha, modelo, versión,
  parámetros, TTFT, latencia, tokens, costo, recursos y resultado del Quality Gate
